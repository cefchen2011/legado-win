# legado 阅读 · Windows

把 [phoenix0451/legado-plus](https://github.com/phoenix0451/legado-plus)（阅读Sigma，Android/Kotlin）
移植到 Windows 桌面。

**核心逻辑复用上游代码，而非重写**——书源规则引擎、书源 JS API 面、书籍抓取链路、
本地书解析、RSS 解析都是 legado 的原版实现，通过一层 Android API 兼容层跑在 JVM 上。

---

## 快速开始

需要 **Java 17 或更高版本**（可用 `JAVA_HOME` 指定）。

```
1. 打包（首次）        gradle :app:installDist      然后  pwsh tools\package.ps1
2. 启动               双击 dist\legado-win.cmd
                      或   pwsh dist\launcher.ps1 -NoBrowser   （只跑服务）
3. 浏览器访问          http://127.0.0.1:8765
```

启动器参数：

| 参数 | 说明 |
|---|---|
| `-Port 9000` | 指定端口（默认自动挑 8765 起的空闲端口） |
| `-DataDir D:\xx` | 指定数据目录（可放 U 盘，随包带走） |
| `-NoBrowser` | 只启动服务，不自动开浏览器 |

## 功能

**阅读**

- 书架（列表/分组筛选/移出）、搜索、发现、订阅
- 在线书源阅读：目录、正文、换源信息、续读
- **换源**：当前书源慢或失效时，一键切到别的有同一本书的书源（保留阅读进度）
- **漫画阅读**：书源类型为「图片」时自动走图片阅读器（竖向连续滚动、懒加载、上下话切换）
- **视频播放**：书源类型为「视频」时自动走播放器（播放完自动下一集）
- **音频播放**：书源类型为「音频」时走音频播放器（有声书，播放完自动下一集）
- 本地书阅读：TXT（26 条官方分章正则）、EPUB
- **词典查询**：正文里选中词即可查（词典为规则式，与书源同构）
- 订阅源：分类、文章列表、正文、已读标记
- 朗读：逐段朗读 + 当前段高亮 + 语速/音色 + 读完自动下一章
- 阅读设置：字号、行距、段间距、段落缩进、两端对齐
- **主题编辑器**：6 套内置主题 + 自定义；7 项配色（背景 / 正文 / 次要文字 /
  面板 / 分隔线 / 主色 / 强调色）日间夜间各一套，带实时预览，可另存为命名主题
- 书签、阅读历史（含累计阅读时长）

**管理**

- 书源：导入（JSON）、导出、启用停用、删除
- **书源仓库**：直接在应用内搜索并导入书源（单个或整个合集，来自 Yiove 书源仓库）
- **批量检测书源**：逐源试探，挑出失效源并一键停用或删除（导入整包书源后很有用）
- 书源管理：按分组/名称筛选，批量启用·停用·删除（只作用于当前筛出的那批）
- 订阅源：导入、分类浏览
- 替换净化：正则替换广告/水印，阅读时自动应用
- **书源调试**：实时查看规则执行过程（每条规则取了什么、哪一步为空），排查失效书源
- **导出书籍**：把整本书导出为 TXT（在线书逐章抓取，本地书直接读；
  支持指定章节范围，个别章节抓取失败不会中断整次导出）
- **备份与恢复**：用户数据（书源/书架/进度/设置/订阅）整体导出与导入
- **WebDAV 同步**：备份上传到自己的 WebDAV（坚果云等），换设备时一键恢复

## 试着跑一遍（不依赖任何外部网站）

服务内置了一套自测数据：

```
1. 打开「书源」页 → 点标题栏，或直接访问
   http://127.0.0.1:8765/api/mock-source?import=1     ← 导入自测书源
2. 回「搜索」页，输入任意词（如「测试」）→ 出现 2 本书
3. 点「阅读」→ 目录 3 章 → 正文

订阅源同理：
   http://127.0.0.1:8765/api/mock-rss-source?import=1  ← 导入自测订阅源
```

这套 mock 站点由服务自己提供（`/mock/*`），因此**整条链路可以完全离线验证**，
回归测试也不受外部网站变动影响。

## 数据目录

```
data/
├── db/          书源、书架、章节、书签、订阅等（JSON 表）
├── prefs/       阅读设置
├── cache/       正文缓存、EPUB 封面
└── server*.log  运行日志
```

用 `-DataDir` 可以指定到别处；**重新打包不会清空已有数据**。

## 项目结构

| 目录 | 内容 |
|---|---|
| `compat/` | Android API 兼容层（66 个纯 JVM 实现） |
| `engine/src/main/` | **原样移植的上游 legado 源码**（含 epublib 等） |
| `engine/src/desktop/` | 桌面端手写替代实现（Android 专属设施的 JVM 版本） |
| `app/` | 应用外壳：本地 HTTP 服务 + Web UI |
| `driver/` | 引擎端到端验证驱动 |
| `tools/` | 移植工具链与打包脚本 |

架构、移植边界判定、踩坑经验详见 [`PORTING.md`](PORTING.md)。

### 真实书源实测

导入公开书源合集后，用真实网站实测过完整链路：

| 环节 | 结果 |
|---|---|
| 搜索 | 0.6s 返回 5 本真实书籍 |
| 目录 | 559 章，真实章节标题 |
| 正文 | 3112 字真实正文，引擎自动排版 |

搜索采用**流式返回**（SSE）：哪个书源先响应就先显示哪个源的结果，
失败的源会连同原因一起列出，不会让个别卡住的源拖住整次搜索。

书源多起来之后（整包导入常有上千条），可以**按整组书源搜索**——
搜索框右侧选择「【整组】听书源」这类入口即可。实测同样的关键词：

| 范围 | 源数 | 结果 | 耗时 |
|---|---:|---:|---:|
| 全部 | 150 | 2365 | 45.0s |
| 整组「听书源」 | 24 | 185 | **1s** |
| 整组「漫画源」 | 35 | 192 | 6.7s |

搜索结果是**按书聚合**的：同一本书的多个源合并成一条，标出「N 个源」，
点「换源」可以展开挑具体用哪个源。实测 185 条原始结果聚合成 41 本不重复的书。
